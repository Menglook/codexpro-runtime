# Quickstart

This guide validates the public source preview without publishing packages, starting public tunnels, or connecting external accounts.

## Requirements

- Node.js 20 or newer
- npm
- Git
- A disposable or reviewed local directory

## Clone and install

```bash
git clone https://github.com/Menglook/codexpro-runtime.git
cd codexpro-runtime
npm ci --ignore-scripts --no-audit --no-fund
```

The initial install uses `--ignore-scripts` so dependency lifecycle scripts are not executed during source verification.

## Run the public checks

```bash
npm run typecheck
npm run build
npm run cli:help
npm run pack:dry-run
```

Expected outcomes:

- TypeScript type checking exits successfully.
- `dist/` is generated by the build.
- CLI help prints without requiring credentials or external services.
- npm reports the future package contents without publishing anything.

## Inspect the entry points

```bash
node dist/stdio.js --help
node dist/http.js --help
node scripts/codexpro-cli.mjs --help
node scripts/codexpro.mjs --help
```

The package names `codexpro-mcp`, `codexpro-mcp-http`, and `menglook-codexpro` are reserved in the local package manifest. They are not currently installable from npm.

## Run a local stdio server

The stdio server is intended to be launched by an MCP client. Review the workspace root and allowed-root configuration before connecting it.

```bash
node dist/stdio.js --root /path/to/repo --allow-root /path/to/repo
```

Stop the process with `Ctrl+C`.

## Run a local-only HTTP server

For trusted loopback testing only:

```bash
CODEXPRO_ALLOW_NO_HTTP_TOKEN=1 node dist/http.js \
  --root /path/to/repo \
  --allow-root /path/to/repo \
  --host 127.0.0.1 \
  --port 8787
```

Do not use the no-token override on a public or non-loopback endpoint. Public and tunnel deployments must use authentication.

## Safer first configuration

Start with the smallest capability set that serves the task:

- one repository-specific root;
- Bash off or safe;
- generic writes off for inspection-only tasks;
- no public tunnel;
- no Codex transcript access unless required.

Read [Security model](security-model.md) before enabling broader capabilities.

## What this quickstart does not do

It does not:

- publish `@menglook/codexpro`;
- create a GitHub Release;
- configure ChatGPT Developer Mode;
- create or modify a Cloudflare or ngrok tunnel;
- provide a hosted relay;
- access a private production configuration.
